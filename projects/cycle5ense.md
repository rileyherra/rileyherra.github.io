## Overview

Cycle5ense is a web application created to help encourage better recycling habits around the UH Mānoa campus. The site includes an interactive map showing recycling bin locations, information about what can and cannot be recycled, campus recycling statistics, and updates related to sustainability efforts.

This project was developed as part of a group effort with classmates during Spring 2026.

<div style="clear: both;"></div>

## My Contributions

I mainly worked on the visual side of the website using React, TypeScript, and CSS. I helped improve the site's color scheme, typography, and overall layout to make the experience feel cleaner and more interactive.

I also implemented React Bits components like the 'Circular Gallery' and 'Count Up' animations to make the site feel more dynamic and visually engaging.

## Features

- Interactive map of recycling bin locations across campus
- Information about recyclable and non-recyclable materials
- Campus recycling statistics and sustainability tracking
- Announcements related to Bottles4College
- User accounts that allow students to track their personal recycling impact
